- Little Help project marked clearly as **UPCOMING / IN DEVELOPMENT**, with a long-term global-community vision
- Personal philosophy and Instagram contact

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.
5. Run `npm run build` to create a production build in `dist/`.
